# Active research plan

The current strongest historical baseline is learned-query set regression. Existing fixed three-channel results establish neither novelty nor observation-based robotics.

1. Preserve and hash historical artifacts; run historical tests and a representative checkpoint evaluation.
2. Build grouped multi-wall variable-opening controlled data with exact segment checks and independent TRAIN/DEV_MODEL/DEV_SCORE/CALIBRATION/TEST_LOCKED/OOD_LOCKED splits.
3. Diagnose plain set regression on K=1/2/4/8. First isolate the variable-positive-set assignment problem: random K-reference supervision can average mutually incompatible passages. Compare an all-positive rectangular assignment control at equal scene/update/route exposure. Treat this as a stronger baseline, not automatic novelty.
4. Test route-set completion only after locating the remaining bottleneck. Compare ordinary draft attention with explicit idempotent coverage memory using duplicate and invalid drafts; include inference passes in budgets.
5. In parallel verify original papers/official code and prepare genuine Qwen RGB/language features and RLBench restored-state data. Observation inputs must exclude true goals, task low-dimensional state and full oracle geometry.
6. Follow each completed run with per-parent error analysis and a concrete next experiment. Use development splits for all decisions. Lock final tests only after methods and evaluator stabilize.
7. Expand promising mechanisms to three true training seeds, independent layout/task setting, ablations, observation training and strong alternatives before claiming an initial paper is established.

Current phase: implementation and resource/data verification, no V2 effectiveness claim.
