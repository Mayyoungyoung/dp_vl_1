# Concrete-path edit diagnostic

Read all completed initial and five ordinary-control predictions on the32
registered DEV_MODEL families. Each target has open/closed/shifted observations.
Test open-to-closed, open-to-shifted and their reverse directions, keeping the
entire original path and event sequence unchanged. Verify start and goals match.
Recheck continuous validity in the destination geometry; failed paths do not
imply an absent mode. A source-valid path that remains valid in the destination
is a concrete positive witness. Count how many such witnessed destination
passage modes the destination model retains, including valid modes outside
the teacher reference set. Count actual geometry-induced invalidations and
the destination generator's adaptation gain over simply reusing source paths.

This is an exploratory diagnostic after the frequency protocol, not a new
primary gate. It uses no new generated candidates and cannot improve a model.
Original q scores are not reused in the changed scene. No probability claim is
made for transferred paths. The result will distinguish frequency loss from
failure to retain paths already known to survive edits, before any new paired
loss is considered. Ordinary edit training remains the strong comparison.
