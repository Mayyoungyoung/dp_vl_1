# 补全机制第一轮独立审查

日期：2026-10-02。对象：commit `73b89d046df2b780a0b306c76e204b3227ee11b0`、服务器 `runs/v2_completion/seed0/{attention,coverage}` 的 DEV_MODEL summary/逐场景预测，以及固定 checkpoint 的 CPU 干预。只读取物理 development 分区，未读取 TEST_LOCKED/OOD_LOCKED 预测，未使用 GPU。

## 判断

coverage 在本轮单种子开发集有积极信号：五种补全情境的平均新增有效类型为 1.61875，attention 为 1.4546875。但当前结果支持的具体假设是**不同有效草稿的特征组合影响剩余路线选择**；不能归因于独有的精确重复幂等性或无效草稿处理。这两项在现有 attention 中也严格成立。尚不能声称方法新颖性、观测任务成立或已击败充分训练的所有强基线。

两个方法同参数量、同初始化形状、同场景/草稿 RNG、同目标池、同 exposure 日程；六种 DEV 情境的原始草稿、present/valid mask、scene/parent ID 已逐元素核验一致。没有发现足以解释收益的候选漏计、无效模式计数或训练/评价信息不对齐 bug。当前待解决的是因果归因和泛化强度，而非把开发均值上涨直接作为研究完成标志。

## 实际实现与预算

两方法都使用 `CompletionRegressor`，width=128、depth=2、403,522 参数。草稿经同一 MLP+sigmoid 得到特征，精确几何 gate 屏蔽无效草稿。attention 用查询相关归一化加权和，coverage 用逐维 max；其余参数结构相同。当前 max 是路径特征的聚合，没有显式模式锚、学习有效性门控或独立证明的语义覆盖记忆。无效 gate 是 oracle 确定性检查且提供给两方法。

训练各 2500 步、batch 64、lr=3e-4、seed 0。每第四步为空上下文输出 4 条，其余步输出 2 条并随机采六种上下文，因此其他步也可能采到空上下文。每项共反传 400,000 个目标槽；所有已有效覆盖类型从正参考池移除，若已覆盖全部已知类型则回退完整正池。各方法用相同 saturation 目标，不把未知解或未匹配输出判负。

评估预算为 empty：0 草稿+4 新候选；single：1 草稿+2 新候选，总数 3；其他：2 草稿+2 新候选，总数 4。重复和无效草稿仍计入总候选。不同情境的原始 union 分数不能在忽略这些预算差异后直接比较。本轮草稿来自参考和人为验证的失效路线，属于**给定草稿的补全**；还没有模型自行产生首批草稿、计入其成本的端到端 K 候选结果。

attention 用时 205.332 s，coverage 192.880 s，包含训练与周期开发评价；分配时段分别为 0.05704/0.05358 GPU 小时，非按利用率积分的能耗。最终 checkpoint 分别选择 step 2500 和 2000。两者都训练至 2500；coverage 在最后一步的选择分数为 1.5953125，低于其 2000 步最优值。不能把早停 checkpoint 的步数误当作完整实验训练成本。

## 收益和失败在哪里

two_valid 的 256 个新候选中：

| 计数 | attention | coverage |
|---|---:|---:|
| 无效新候选（均为碰撞） | 53 | 48 |
| 新候选中有效类型数之和 | 195 | 194 |
| 其中与已有有效草稿重叠的类型数 | 67 | 42 |
| 新增有效类型数之和 | 128 | 152 |
| 新候选内部的有效重复数 | 8 | 14 |

R=3 时两模型有效率相同，但 coverage 全部 17 个场景都补到唯一剩余类型；这是比全表均值更直接的覆盖条件证据。R=4 贡献了最多新增改善；R=9/12 的退化必须保留。所有已知类型已覆盖的 26 个 two_valid 场景没有可要求的新增类型，正确目标是保留有效候选，而不是强迫制造新模式。

single 的新增总数 183→216，主要是碰撞 42→6；与已有类型重叠均为 8。mixed 类似，碰撞 38→12、已有类型重叠均为 8。空上下文也有 25→10 个碰撞改善。这些收益更像联合训练/表征优化后的转移，不能称为运行时覆盖操作在单条上下文中具有独有优势。

原评估每种 kind 使用不同 RNG。single 与 duplicate 的首条草稿仅 32/128 场景完全相同；二者分数差不是重复干预效果。下面固定草稿诊断已消除该混淆。

## CPU 固定草稿/固定 checkpoint 干预

脚本：[diagnose_completion.py](../scripts/diagnose_completion.py)，SHA256 `8584e7cb7fe13cab9c578c9916cfeda91bc509db1054e0f0e9e43406098ed59d`。CPU 1 线程，显式隐藏 CUDA，读取 immutable release 与 development 分区；保存 `runs/v2_completion/diagnostics_seed0.json`。CPU 重放与原 GPU 路点最大绝对差均为 6.56e-7，评价数值一致。

固定同一组 two_valid 草稿 `[A,B]`，在内存中替换聚合运算而不改变权重：

| 训练权重 | 推理池化 | 新 Valid | 新 UniqueValid | 新增有效类型 |
|---|---|---:|---:|---:|
| attention | attention | 79.2969% | 1.523438 | 1.000000 |
| attention | max | 59.7656% | 1.132813 | 0.757813 |
| coverage | max | 81.2500% | 1.515625 | 1.187500 |
| coverage | attention | 93.3594% | 1.804688 | 0.992188 |

coverage 权重换成 attention 时产生更多有效路线，却更常回到已有类型，新增覆盖下降；attention 权重直接换 max 也明显失败。这支持“所学特征与池化共同影响剩余方案”的诊断，但替换造成训练外表征分布变化，**不是公平训练消融，也不证明 max 的普遍优越性**。不能把运行时替换当成直接部署改进。

对每个 checkpoint 固定同一 A，分别构造 `[A]`、`[A,A]`、`[A,无效B]`。无效 B 通过把中间点放入障碍并经完整检查确认。两个模型在原池化下这三者的输出逐元素完全相同；attention 的精确重复幂等性、两者的硬门控屏蔽均得到实测。对 `[A,B]` 换序，max 差为 0，attention 只有约 6.1e-7 的浮点差，类型/有效性不变。

近重复干预为第二条 A 的 y 坐标叠加幅度 0.002、首尾为 0 的正弦扰动；全部草稿仍经检查有效。attention 最大输出坐标变化 0.01234，coverage 0.001434；但两者都新增 1/256 个碰撞，coverage 还少 1/128 个新增类型。只能报告这一小扰动下的连续响应，不能由更小坐标变化声称近重复质量更鲁棒。最多 2 条草稿也无法检验 `[A,B]→[A,A,B]` 的混合集合重复不变性。

## 下一轮应作出的最小研究决定

1. 先按现有原配方完成 seed 1/2 的 **attention 与 coverage 配对**，检查 R=3/4 的少重叠现象和 R=9/12 退化是否重复。父场景区间不能代替训练种子，不能只补跑有利方法。父 agent 已开始这一轮。
2. 暂不增加模型模块。attention 最优点在训练末端、训练损失仍下降，2500 步不足以排除优化差异；若三种子方向稳定，优先给两方法同样的更长预算检查曲线，或加入同参数的普通 sum/mean 集合聚合作为最小近邻消融。只能挑一个当前证据最需要的验证，不同时堆叠。
3. 主要可证伪目标定为“两个不同有效草稿下，减少已覆盖类型重叠而不牺牲过多有效性”。普通 max pooling 自身不新；若优势只来自更容易优化的聚合，应降级表述并保留为工程基线。
4. 后续升级场景前需用同一模型生成首批草稿，固定总 K 并计入失败/重复与生成时间。当前 oracle gate 和参考草稿下的收益不能提前外推到 learned gate、真实 Qwen 观测输入或机器人执行。

本轮是值得继续验证的积极开发结果；核心证据仍不完整。没有理由因一次改善立即宣布成功，也没有理由在尚未定位优化/聚合效应前增加扩散、LoRA 或更多辅助损失。
