日期：2026-10-02。设计依据是现有 `routeset/models.py` 的 `SetRegressor` 与已核验近邻工作。当前基线已有学习查询、候选 self-attention 和集合匹配；候选方法不能改名复用这些组件来宣称创新。文献状态及源码检查见 [RELATED_WORK_MATRIX.md](RELATED_WORK_MATRIX.md)。本文件只提出两个可证伪机制；是否已实现、是否有效以实验登记、日志和逐场景结果为准。

## 候选 A：有效覆盖记忆驱动的路线补全（优先）

**具体不足。** 普通回归器根据场景一次生成 K 条路线，不显式接受已有方案。直接添加路径 attention 虽能读取草稿，但 attention 对重复次数可能敏感，也可能把穿障或错误目标草稿视为“某个方案已经存在”。当预算小于可行路线类型数时，浪费一个候选就会降低实际可选性。需要先在新开发集观察这些失效，不能预设基线必然失败。

**最近工作与差异。** DETR/Set Transformer 支持集合预测和集合交互；MTR 读取轨迹相关地图并细化；LED/Particle Guidance 学习或引导相关样本；条件 DPP/同伦约束搜索已经会排除已覆盖选项。Multi-Path Reflection 还会读取多种未来来改进动作。因此本候选的可研究差异只能是**任务条件下、对重复和无效草稿稳健的覆盖状态，以及由该状态驱动的剩余正例学习**，不能声称首创已有集合条件化、attention 或边际多样性。

**最小机制。** 令条件为 c，已有路线集合 S={s_j}，待生成数为 b。每条完整路线由共享编码器得到 z_j=phi(s_j,c)，有效性估计为 q_j。对一组场景条件锚向量 a_m(c) 形成覆盖记忆：

```text
u_jm = sigmoid(sim(z_j, a_m(c)))
m_m(S,c) = max_j [q_j(c,s_j) * u_jm]       空集合取 0
R_new = decoder(c, budget=b, memory=m)
```

锚向量是连续可训练表示，不把测试模式 ID 输入网络。初版可保留现有路线 MLP 与查询解码器，仅增加路线编码器、门控和 memory 条件。max 聚合使相同路线重复输入时记忆严格不变；近重复稳定性仍需测量，不能从精确重复的代数性质推出。连续特征的 max 不自动等于真实路线类别覆盖，需通过诊断和消融检验。

受控层 A 可用确定性几何/任务检查产生 q，且同样的检查结果提供给所有相应基线。观测层 B 推理的 q 必须仅依赖当前观测、指令和路线；仿真验收只能用作训练/评估监督。不得把 oracle gate 在 B 层的结果写成部署性能。q 是任务层有效性估计，不是机器人执行成功概率。

**训练。** 从同一父场景的已知正参考中构造部分集合，统一包含空集合、单条、两条不同有效路线、两条近重复路线、经过检查的无效草稿。只将**确实有效且与已知正例属于同一评价类型**的草稿计为已覆盖，再对剩余已知正例做匹配。没有采到的模式保持未知；不监督“真实解总数”。若剩余已知类型少于 b，允许同类有效变体，不强迫补出不存在的新模式，也不把未匹配输出一律监督为无效。后期加入同训练集模型草稿并记录来源；DEV/TEST 草稿不回流训练。

目标路径曝光量按真正被监督的路线计数；基线也使用相同补全样本、草稿难度、目标路径曝光和更新步数。基线的路径 attention 输入同一 S 和同一可用 q，避免收益来自额外信息。

**第一组有区分力实验。** 在父场景留出的变量通道/多障碍开发集、单个训练 seed 下，K=1/2/4/8，先训练普通集合回归和普通路径 attention 补全，再比较有效覆盖记忆。优先保持同一主干、数据、损失、训练曝光和批量；按数据能力选择一个主 K，其他 K 作预算泛化诊断。逐场景保存 Valid、UniqueValid、ReferenceCoverage、重复率和原始预测；分开报告 0/1/2 个上下文条件以及完美、重复、无效、模型自生成草稿。

**必要消融。** 普通路径 attention；同 memory 去掉 q；max 换 mean/sum；只训练干净草稿；不读取 S；受控层的 oracle q 与观测可用 q 分开。先做最能区分机制的两项，不并行堆十个模块。

**可证伪现象。** 若 max/gate 在重复或无效条件下没有优于同训练的 attention，核心机制不成立；若只在参考草稿有效，在模型草稿无效，需排查分布差异后混合训练；若 UniqueValid 上升伴随明显有效率/延迟恶化，只能报告 Pareto 取舍；若仅空集合收益而上下文不敏感，可能来自容量或训练变化；若优势仅来自二次生成/修复，必须加入相同更新成本基线。

**预算与成本。** 外部提供的 S 要明确来源，不当成免费模型生成。闭环从空集合开始时，先生成 r 条、再生成 K-r 条，总共 K 条；失败和重复不补发。若对已有 K 条做第二次坐标细化，记录更新次数、全部中间候选、检查次数和实际耗时，不仅报告最终 K。单请求计时包含 Qwen、几何、门控、路线更新和评分；缓存条件只报告模块吞吐。

**保留标准。** 在配对 DEV 父场景下对强基线取得可靠的有效覆盖改善，并能通过重复/无效干预解释来源，才扩到三训练种子及观测机器人数据。低成本筛选证据不能替代 Qwen/RLBench 主结果。

## 候选 B：条件改变时的保留—替换学习（后备，先不与 A 叠加）

**具体不足。** 场景或指令只改变一项约束时，重算整个集合可能丢失仍正确的路线；无条件保留旧集合则会留下错误方案。目标是小更新预算下保留有效选项并替换失效选项，不是低层轨迹控制。

**最近工作与差异。** MTR 已有迭代轨迹细化；传统增量/同伦搜索及 Multi-Path Reflection 已用历史候选或多种后果指导更新。待检验机制是：用可观测条件差异重新评估每条旧路线，学习保留兼容部分和补足受影响部分，同时明确惩罚无意义变动。不能将成对数据增广或再做一次前向本身写成贡献。

**最小机制。** 构造 (c_old,c_new,S_old) 配对，二者只改变目标或一个可观测约束。模型重新编码 `phi(s_j,c_new)` 和逐路线保留分数；连续路线不做两个不同模式的线性插值，采取保持原路线或生成替换的离散选择。训练以新条件下的正参考匹配为主，对经统一检查仍有效的旧路线使用保留一致性损失；无效路线不施加保留。初版不加 diffusion/flow、不同时加入 A 的显式记忆，保证可解释。

**第一轮。** 先用受控层的“封闭一个已有通道”“移动目标而保持布局”“只改变禁行指令”配对。变化后的观察中必须有约束依据。所有同布局版本在同一 split。比较从头普通集合回归、读取旧路径的普通 attention、保留—替换版本；各方法获得同样 c_old/c_new/S_old、训练路径曝光与允许的更新数。

**指标与计费。** 同时报新条件下 Valid/UniqueValid/ReferenceCoverage、旧的仍有效模式保留率、失效模式替换率、无必要的路径变化量。S_old 是上一次请求的输出：报告两次请求累计生成数与累计时间，也单列本次新增预算。不能生成初始 K 再新增 K，最后只保留 K，仍称总预算 K。

**证伪与退出。** 若从头回归同成本已达到相同质量，保留机制没有必要；若只提高路径稳定而牺牲正确目标或覆盖，不适合作核心；若收益只来自人工提供的失效掩码，则只证明 oracle 上限；若小约束改变无法形成真实多路线差异，换任务而不是改变评价标准。仅当 A 在合理排查后无收益，或真实应用明确需要频繁条件更新，再推进此候选。

## 共同边界和下一决策依据

- 层级 A 的完整几何、已知端点结果与层级 B 的 RGB-D+指令结果分表；不以 A 证明语义规划。
- 原三路数据继续做历史回归。新机制筛选只用 DEV_MODEL；评分和校准各用独立父场景；锁定测试在主方案确定后才运行。
- 第一阶段主张只限定为具体失效机制。完整方法主张需要实际 Qwen、代表性机器人数据、强对照、三训练种子与独立设置。
- 不将失败正则、草稿分布或门控失败藏在平均数中。每轮读失败样例后决定保留、修改或切换，不靠增加 seed 碰运气。
- 文献核验未发现本候选与某一单篇工作完全相同，不代表已经证明新颖；特别应持续对照 conditional DPP、子模覆盖、集合补全与机器人测试时规划。
